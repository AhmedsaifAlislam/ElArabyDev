## 1) ترتيب الحسم (Resolution Pipeline)

| # | الطبقة | الشرط | النتيجة |
|---|--------|-------|---------|
| 1 | `input_exact` | اسم فني قادم من Input/Messenger ويطابق اسمًا كانونيًا في البورتال **بمطابقة exact بعد normalize** | يُختار هو |
| 2 | `region_mapping` | لا يوجد هدف، لكن Region موجودة وتوجد لها صف في `REGION_TECH_MAP` | يُختار فني المنطقة |
| 3 | `random_fallback` | لا هدف ولا Region معروفة | عشوائي من القائمة المعروفة — **معلَن ومسجَّل، ليس نجاحًا صامتًا** |
| 4 | `failed` (`ok:false`) | القائمة نفسها فارغة | لوج خطأ و**متابعة الـ batch — لا إيقاف** |

- أي «miss» ينزل للطبقة التالية. لا طبقة تُعيد المحاولة أو تخلط مصدرين.
- **الفلسفة:** نقص معلومة الفني = Data Quality Warning وليس Task Failure.

## 2) مصدر القرار — enum مغلق

```
input_exact | region_mapping | random_fallback
```

ممنوع أي قيمة أخرى، وممنوع نجاح بلا `source`.

## 3) عقد الإرجاع (Return Contract)


## 6) الأسماء الكانونية في البورتال (حاسمة للـ exact matching)

```
AC522 & محمد محمود امين محمد
AC522 & يوسف محمد يونس
```

- المطابقة: normalize whitespace ثم **مساواة تامة فقط — ممنوع `includes()` نهائيًا**.
- ⚠️ **بند تحقق إلزامي (ضمن R1/اللقطات الحية):** تثبيت الرسم الإملائي النهائي للأسماء من DOM البورتال الحي (أمين/امين) قبل اعتماد الخريطة والأسماء الكانونية نهائيًا.

## 7) العلاقة مع P0-B — تكامل، لا تعارض، ولا لمس

- **P0-B (ثابت كما هو):** «عندي فني محدد ← لا تختار شخصًا آخر بصمت» = الطبقة 1 صارمة.
- **Technician v2:** «معندناش فني محدد ← لا توقف العملية؛ جرّب المنطقة، وإن غابت كل المعلومات اختر عشوائيًا وسجّل».
- ليست عودة للعشوائية القديمة: العشوائية الآن **آخر طبقة حسم، معلنة، ومقيسة في الـ telemetry**.
- نقطة الدمج: داخل مسار الفني بعد فشل exact وفبدل السقوط الصامت — دون تغيير سلوك P0-B.

## 8) Telemetry — الهدف القابل للقياس

تجميع عدّادات `source` من السجلات قبل وصول أداة Messenger، بشكل مثل:

```

---------------------
input_exact       62%
region_mapping    31%
random_fallback    7%
failed             0%
```

(الأرقام مثال توضيحي — تُقاس فعليًا في مرحلة الـ Runtime Observation.)

## 9) حدود التنفيذ

- **ملف واحد:** `src/unified-extension/content-script.js` فقط — ثابت `REGION_TECH_MAP` + `normalizeRegion()` + توسيع شكل الإرجاع + أسطر اللوج (تقدير ~40–60 سطرًا).
- **ممنوع:** لمس P0-B، تغيير أي سلوك قائم آخر، حذف/نقل/refactoring، Deploy، Save/Submit/Finalize.
- **مؤجَّل صراحةً:** استرجاع الـ48 selector (إلا R3/R4 كدليل configuration layer)، وتنظيف الـ37% duplicate code — لا تنظيف قبل حسم src-vs-deploy.

## 10) مسار التنفيذ المعتمد

1. **R1** — حسم نسخة التشغيل (src مقابل deploy؛ deploy = لقة ما قبل P0-B) + التقاط الأسماء الكانونية الحية (§6).
2. **R2** — تنفيذ هذا المواصف (بعد إذن صريح).
3. **Runtime Observation مراقب** — بدون Save/Submit/Finalize؛ قياس توزيع المصادر.
4. **R3–R5** — errorIndicator، busyIndicator، timeout/retry، stopERP.
