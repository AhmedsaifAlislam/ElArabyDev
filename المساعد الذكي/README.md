# المساعد الذكي لقطع غيار العربي
# Smart Parts Assistant — El Araby

> إضافة متصفح شاملة لإدارة قطع غيار مراكز صيانة العربي — بحث ذكي, حقن تلقائي, إدارة عهدة, ولوحة تحكم متكاملة.

---

## التثبيت / Installation

### Chrome
1. افتح `chrome://extensions`
2. فعّل **Developer mode** (الزاوية العلوية اليمنى)
3. اضغط **Load unpacked**
4. اختر مجلد `المساعد الذكي`

### Edge
1. افتح `edge://extensions`
2. فعّل **Developer mode** (المفتاح في الأسفل اليسار)
3. اضغط **Load unpacked**
4. اختر مجلد `المساعد الذكي`

> **ملاحظة:** يجب أن يحتوي المجلد على `manifest.json` مباشرةً (ليس داخل مجلد فرعي).

## طريقة الاستخدام / Usage

### 1. تهيئة البيانات
1. افتح لوحة التحكم بالنقر على أيقونة الإضافة → **فتح لوحة التحكم**
2. اذهب لتبويب **إدارة البيانات**
3. ارفع ملف Excel/CSV يحتوي على بيانات قطع الغيار
4. أو قم بمزامنة من Google Drive

### 2. البحث عن قطع الغيار
1. افتح صفحة البلاغ في البورتال
2. اضغط على الدائرة العائمة (اللوحة المنبثقة)
3. اختر تبويب **بحث**
4. اختر نوع المنتج → الموديل → العطل → وصف العطل
5. اضغط **بحث**
6. ستظهر النتائج مع السعر وكمية القطعة

### 3. حقن البيانات في البورتال
1. من نتائج البحث، اضغط **حقن** بجانب القطعة المطلوبة
2. أو أضف القطعة إلى **عربة التسوق** ثم حقنها من هناك
3. سيتم ملء الحقول تلقائياً في نموذج البورتال

### 4. فتح لوحة التحكم
- **النقر الأيمن** على أيقونة الإضافة → **فتح لوحة التحكم**
- أو اضغط على أيقونة الإضافة → **فتح لوحة التحكم**

## إعدادات / Settings

### البحث
- `*text` → بحث بالاحتوائية (contains)
- `text` → بحث بالبداية (startsWith)
- البحث غير حساس لحالة الأحرف

### التخزين
- قاعدة البيانات: IndexedDB (`ElArabyPartsDB` v2)
- التخزين المحلي: `chrome.storage.local` (عبر background.js)

---

## ملاحظات مهمة / Important Notes

1. **Edge Tracking Prevention** — `chrome.storage.local` لا يعمل في content scripts على Edge
   - الحل: كل التخزين يمر عبر `background.js`

2. **Shadow DOM** — واجهة المستخدم في البورتال تُحقن عبر Shadow DOM
   - هذا يتجنب تضارب الأنماط مع البورتال

3. **البحث في iframes** — البورتال يعمل على PowerApps
   - الجداول دائماً داخل iframes
   - يجب البحث في `document` + كل الـ iframes

## 해결 المشاكل / Troubleshooting

| المشكلة | الحل |
|---------|------|
| لا تظهر نتائج البحث | تأكد من رفع بيانات قطع الغيار أولاً |
| اللوحة المنبثقة لا تظهر | أعد تحميل صفحة البورتال |
| حقن البيانات لا يعمل | تأكد من أنك على صفحة صحيحة في البورتال |
| قاعدة البيانات فارغة | ارفع ملف Excel/CSV من تبويب إدارة البيانات |
