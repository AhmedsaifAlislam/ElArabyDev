## الغرض الرئيسي / Purpose

> أداة سطح مكتب مبنية بـ Python لتنسيق ملفات Excel المشفرة للطباعة، بشكل تلقائي. تُستخدم لتحويل بيانات البلاغات إلى ملفات Excel منسقة جاهزة للطباعة بتنسيق RTL مع عناوين متكررة كل 30 سطر.

## البنية التقنية / Architecture

### التقنيات المستخدمة
- **Python** — اللغة الأساسية
- **CustomTkinter** — واجهة المستخدم
- **openpyxl** — قراءة/كتابة Excel
- **threading** — المعالجة الموازية

### آلية العمل
```
1. المستخدم يختار ملف Excel
2. الأداة تقرأ الأعمدة المطلوبة (CaseNumber, SAPOrderNumber, Quantity, Product, ProductType)
3. تعيد تنسيق البيانات بتنسيق RTL
4. تضيف عنوان متكرر كل 30 سطر
5. تحفظ الملف الجديد جاهزاً للطباعة
```
