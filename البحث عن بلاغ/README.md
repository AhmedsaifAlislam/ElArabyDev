# استخراج التقارير — البحث عن بلاغ
# Report Extractor

> إضافة متصفح (Chrome MV3) لاستخراج تقارير البلاغات من بوابة CRM العربي.

---

## التثبيت / Installation

### Chrome
1. افتح `chrome://extensions`
2. فعّل **Developer mode**
3. اضغط **Load unpacked**
4. اختر مجلد `البحث عن بلاغ`

### Edge
1. افتح `edge://extensions`
2. فعّل **Developer mode**
3. اضغط **Load unpacked**
4. اختر مجلد `البحث عن بلاغ`

---

## طريقة الاستخدام / Usage

### 1. تجهيز ملف Excel
- يجب أن يحتوي الملف على عمود يحتوي أرقام البلاغات (CRM/CAS)
- يمكن أن يكون العمود بعنوان: "بلاغ"، "CAS"، "CRM"، "رقم"
- يمكن أن يحتوي الملف على أعمدة أخرى — سيتم حفظها

### 2. فتح صفحة البحث
1. افتح `https://elarabyiscrm2.azurewebsites.net/ASPPage/SelectReport.aspx`
2. تأكد من تسجيل الدخول

### 3. رفع الملف والبحث
1. اضغط على أيقونة الإضافة
2. اختر ملف Excel
3. اضغط **بدء الاستخراج**
4. ستظهر خطوات التقدم
5. عند الانتهاء، سيتم تحميل ملف Excel محدث بالتقارير

### 4. مراجعة النتائج
- الملف الجديد يحتوي على الأعمدة الأصلية + أعمدة التقارير الجديدة
- كل بلاغ له تقرير أو أكثر بجانبه

## ملاحظات مهمة / Important Notes

1. **حجم الدفعة:** 25 رقم/مرة — لتجنب حمل البورتال
2. **الحالات المفلترة:** `canceled` و `postpone` يتم تجاهلها
3. **التنقل بين الصفحات:** يدعم Pagination تلقائياً
4. **البيانات المحفوظة:** تُحفظ في `chrome.storage.local` بين العمليات

## حل المشاكل / Troubleshooting

| المشكلة | الحل |
|---------|------|
| لا يتم كشف الأعمدة | تأكد من أن الملف يحتوي عمود بعنوان "بلاغ" أو "CAS" |
| البحث يعلق | أعد تحميل الصفحة وابدأ من جديد |
| النتائج غير مكتملة | تحقق من عدد الصفحات في الجدول |
| الملف غير محدث | تأكد من ضغط "تحميل النتائج" بعد الانتهاء |
