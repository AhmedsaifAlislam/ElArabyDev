## الغرض الرئيسي / Purpose

> إضافة متصفح (Chrome MV3) متخصصة في استخراج وبحث تقارير البلاغات من بوابة CRM العربي. تقرأ ملفات Excel المرفوعة، تستخرج أرقام البلاغات، تبحث عن كل بلاغ في جدول CRM، تستخرج التقارير المرتبطة، وتعيد ضبط البيانات في ملف Excel الأصلي مع أعمدة التقارير الجديدة.

## البنية التقنية / Architecture

### Manifest V3
```json
{
  "manifest_version": 3,
  "name": "استخراج التقارير",
  "version": "5.0.0",
  "permissions": ["storage"],
  "host_permissions": ["https://elarabyiscrm2.azurewebsites.net/*"],
  "content_scripts": [{
    "matches": ["https://elarabyiscrm2.azurewebsites.net/ASPPage/SelectReport.aspx*"],
    "js": ["content.js"],
    "run_at": "document_idle"
  }],
  "web_accessible_resources": [{
    "resources": ["xlsx.full.min.js"],
    "matches": ["https://elarabyiscrm2.azurewebsites.net/*"]
  }]
}
```

### آلية العمل
```
1. المستخدم يرفع ملف Excel يحتوي أرقام CRM/CAS
2. السكريبت يقرأ الأرقام من العمود الذي يحتوي "بلاغ" أو "CAS" أو "CRM"
3. يبحث عن كل رقم في البورتال (دفعات من 25 رقم)
4. يستخرج التقارير من عمود "تقرير الاصلاح" و "حالة المركز"
5. يحفظ النتائج ويسمح بتحميل ملف Excel مع التقارير
```

## نقاط القوة / Strengths

1. **كشف تلقائي** — يكتشف الأعمدة تلقائياً من ملف Excel
2. **دفعات منظمة** — لا يحطل البورتال حمل
3. **تنقل بين الصفحات** — يدعم Pagination
4. **تصفية ذكية** — يتجاهل البلاغات الملغاة والمؤجلة
5. **إعادة ضبط** — يحفظ البيانات الأصلية ويضيف التقارير

## المشاكل المعروفة / Known Issues

1. **حساب عمود التقرير** — قد يكون غير دقيق في بعض الحالات
   - **الحل:** التأكد من أن ملف Excel يحتوي عمود "تقرير"

2. **التنقل بين الصفحات** — قد يتعطل إذا كان هناك تغيير في بنية الصفحة
   - **الحل:** مراجعة `content.js` وتحديث selectors التنقل

3. **حجم الدفعة** — 25 رقم/مرة قد يكون بطيئاً للكثير من الأرقام
   - **الحل:** تعديل `BATCH` في `content.js`
