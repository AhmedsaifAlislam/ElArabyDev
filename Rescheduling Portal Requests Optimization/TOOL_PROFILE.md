## الغرض الرئيسي / Purpose

> سكريبت Tampermonkey لتجاوز قيود عدد الأيام ومرات الجدولة في بوابة العربي. يحقن زراً عائماً في صفحة العمل (workorderreview) يتيح جدولة حرة بدون القيود المفروضة من البورتال.

## البنية التقنية / Architecture

### Tampermonkey Header
```javascript
// ==UserScript==
// @name         El Araby Portal - Smart Scheduler (الجدولة الذكية)
// @namespace    http://tampermonkey.net/
// @version      1.1
// @description  تجاوز قيود عدد الأيام ومرات الجدولة في بوابة العربي
// @match        https://elarabyportalpfs.powerappsportals.com/*
// @grant        none
// ==/UserScript==
```

### آلية العمل
```
1. التحقق من أننا داخل صفحة workorderreview
2. حقن زر عائم "جدولة حرة (بدون قيود)"
3. فتح نافذة منبثقة لاختيار التاريخ
4. تنفيذ الجدولة عبر API البورتال
```

## المشاكل المعروفة / Known Issues

1. **قيود السيرفر** — قيود الجدولة مقفلة من جانب السيرفر (Dynamics 365 Plugin)
   - **الحالة:** لا يمكن تخطيها برمجياً من المتصفح بالكامل
   - **الحل:** السكريبت يتجاوز القيود العددية فقط

2. **قد يتوقف عن العمل إذا تغير بنية البورتال**
   - **الحل:** تحديث السكريبت حسب البنية الجديدة
