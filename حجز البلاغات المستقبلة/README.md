# كاشف ومتحكم في فلتر تاريخ البلاغات
# Date Filter Unlocker

> سكريبت Tampermonkey لكشف البلاغات المخفية والتحكم الكامل في نطاق التاريخ في بوابة العربي.

---

## التثبيت / Installation

### Tampermonkey
1. ثبّت Tampermonkey من https://www.tampermonkey.net/
2. اضغط على أيقونة Tampermonkey → **Create new script**
3. احذف الكود القديم بالكامل
4. افتح ملف `ElAraby_DateFilter_Unlocker.user.js`
5. انسخ محتواه والصقه
6. اضغط `Ctrl + S` للحفظ

### التشغيل
- يعمل تلقائياً بعد التثبيت
- لا يحتاج أي إعدادات

---

## طريقة الاستخدام / Usage

1. افتح بوابة العربي (`https://elarabyportalpfs.powerappsportals.com`)
2. تأكد من تثبيت السكريبت وتفعيله
3. افتح صفحة البلاغات
4. ستظهر البلاغات المستقبلية (التي كانت مخفية)
5. يمكنك التحكم في نطاق التاريخ بشكل كامل

---

## ملاحظات مهمة / Important Notes

1. **يعمل في `document-start`** — قبل تحميل أي شيء آخر
2. **آمن** — لا يغير أي بيانات في السيرفر
3. **يحذف `futureCases`** — يحذف قيود التاريخ من الإعدادات
4. **قد يحتاج إعادة تحميل** — إذا لم يعمل lầnแรก، أعد تحميل الصفحة

| المشكلة | الحل |
