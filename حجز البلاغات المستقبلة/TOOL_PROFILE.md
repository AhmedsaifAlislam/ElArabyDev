## البنية التقنية / Architecture

### Tampermonkey Header
```javascript
// ==UserScript==
// @name         🗓️ El-Araby Date Filter Unlocker
// @namespace    elaraby.datefilter.unlocker
// @version      1.0
// @description  كاشف ومتحكم في فلتر تاريخ البلاغات
// @match        https://elarabyportalpfs.powerappsportals.com/*
// @grant        GM_getValue
// @run-at       document-start
// ==/UserScript==
```

### آلية العمل
```
1. السكريبت يعمل عند `document-start` (قبل أي شيء)
2. يعترض `window.crmAccount` عبر `Object.defineProperty`
3. يحذف قيود `futureCases` من الإعدادات
4. يراقب طلبات Fetch و XMLHttpRequest
5. يبني واجهة مستخدم (FAB + Panel) بعد تحميل الصفحة
6. يراقب تغييرات DOM لاكتشاف فلتر التاريخ
7. يتعديل استجابات الفلتر تلقائياً
```
